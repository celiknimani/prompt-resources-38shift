# Business Analysis 📊

Professional prompts for data-driven decision making, market research, and strategic planning.

## 📁 Prompt Collection

- `swot-analysis-generator`: Competitive landscape breakdown.
- `financial-report-interpreter`: Extracting insights from quarterly results.
- `market-entry-strategy`: Frameworks for expanding into new territories.

## 📈 Analytical Rigor

- Focus on quantitative data where available.
- Ask for cross-referencing of sources.
- Request "Devils Advocate" perspectives to avoid groupthink.
