# System Instructions ⚙️

Foundational prompts designed to be used in the system role of LLMs to define long-term behavior, persona, and constraints.

## 🛡️ Best Practices

- Use clear, imperative language.
- Define what the model *should not* do (negative constraints).
- Standardize the output format (e.g., "Always respond in Markdown").
