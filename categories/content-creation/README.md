# Content Creation ✍️

Prompts for writers, marketers, and storytellers to generate engaging content and compelling narratives.

## 📁 Prompt Collection

- `blog-post-outline`: Structured frameworks for high-SEO articles.
- `social-media-thread`: viral thread hooks and structure.
- `creative-story-starter`: Narrative prompts with deep character development.

## ✨ Creativity Boosters

- Define the target audience clearly.
- Specify the brand voice (e.g., authoritative, witty, empathetic).
- Use "show, don't tell" instructions for narrative writing.
