# Software Development 💻

Highly technical prompts designed for engineers, architects, and developers to streamline the software development lifecycle.

## 📁 Prompt Collection

- `debugging-assistant`: Systematic approach to identifying and fixing bugs.
- `architecture-reviewer`: Critical analysis of system designs.
- `documentation-generator`: Automating README and API docs.

## 🛠️ Usage Tips

- Provide codebase context where possible.
- Specify the programming language and framework version.
- Ask for "step-by-step" implementation for complex tasks.
